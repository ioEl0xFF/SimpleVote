## 📝 テスト実行手順

### 1. 環境準備
```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev

# テストの実行
npm run test
```

### 2. 手動テスト手順
1. ブラウザで `http://localhost:3000` にアクセス
2. ウォレットを接続（MetaMask等）
3. 各機能を順次テスト
4. エラーケースも含めてテスト

### 3. 自動テスト実行
```bash
# E2Eテストの実行
npm run test:e2e

# 単体テストの実行
npm run test:unit
```

## 📞 サポート

テスト中に問題が発生した場合は、以下を確認してください：

1. **ログの確認**: ブラウザの開発者ツールでコンソールログを確認
2. **ネットワーク接続**: ブロックチェーンネットワークへの接続を確認
3. **ウォレット設定**: MetaMask等のウォレット設定を確認
4. **環境変数**: 必要な環境変数が設定されているか確認
