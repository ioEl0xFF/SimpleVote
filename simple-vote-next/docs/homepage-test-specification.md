# SimpleVote ホームページ テスト仕様書

## 📋 概要

このドキュメントは、SimpleVoteアプリケーションのホームページ（`/`）に対する詳細なテスト仕様を定義します。

### テスト対象
- **URL**: `/`
- **ファイル**: `simple-vote-next/app/page.tsx`
- **コンポーネント**: `HomePage`, `PollListPage`, `PollList`

### テスト環境
- **フレームワーク**: Playwright
- **ブラウザ**: Chrome, Firefox, Safari, Edge
- **デバイス**: デスクトップ, タブレット, モバイル

## 🧪 テスト実装例

### Playwrightテストコード例

```typescript
import { test, expect } from '@playwright/test';

test.describe('ホームページテスト', () => {
  test.beforeEach(async ({ page }) => {
    await page.goto('/');
  });

  test('ページ初期表示', async ({ page }) => {
    // ページタイトルの確認
    await expect(page.locator('h1:has-text("SimpleVote")')).toBeVisible();

    // ウォレット接続ボタンの確認
    await expect(page.locator('button:has-text("ウォレット接続")')).toBeVisible();

    // ページヘッダーの確認
    await expect(page.locator('h1:has-text("投票一覧")')).toBeVisible();

    // 新規作成ボタンの確認
    await expect(page.locator('button:has-text("新規作成")')).toBeVisible();
  });

  test('ウォレット接続', async ({ page }) => {
    // ウォレット接続ボタンをクリック
    await page.click('button:has-text("ウォレット接続")');

    // MetaMaskの接続要求を承認（モック）
    // 実際のテストでは適切なモックを使用

    // 接続後の表示確認
    await expect(page.locator('.font-mono')).toBeVisible(); // ウォレットアドレス
    await expect(page.locator('button:has-text("切断")')).toBeVisible();
  });

  test('投票一覧表示', async ({ page }) => {
    // ウォレット接続
    await page.click('button:has-text("ウォレット接続")');

    // ローディング表示の確認
    await expect(page.locator('text=投票一覧を読み込み中...')).toBeVisible();

    // 投票一覧の表示確認
    await expect(page.locator('h2:has-text("Poll 一覧")')).toBeVisible();
  });

  test('投票項目クリック', async ({ page }) => {
    // ウォレット接続
    await page.click('button:has-text("ウォレット接続")');

    // 投票項目が存在する場合のクリックテスト
    const pollButton = page.locator('button.underline.text-blue-600').first();
    if (await pollButton.isVisible()) {
      await pollButton.click();
      // URL遷移の確認
      await expect(page).not.toHaveURL('/');
    }
  });

  test('新規作成ボタン', async ({ page }) => {
    // ウォレット接続
    await page.click('button:has-text("ウォレット接続")');

    // 新規作成ボタンをクリック
    await page.click('button:has-text("新規作成")');

    // 作成ページへの遷移確認
    await expect(page).toHaveURL('/create');
  });
});
```

## 🔧 トラブルシューティング

### よくある問題と解決方法

1. **ウォレット接続エラー**
   - MetaMaskがインストールされているか確認
   - ネットワーク設定を確認
   - ブラウザの権限設定を確認

2. **投票一覧が表示されない**
   - ブロックチェーンネットワークの接続を確認
   - スマートコントラクトのデプロイ状況を確認
   - コンソールエラーを確認

3. **ページ遷移エラー**
   - Next.jsのルーティング設定を確認
   - ページコンポーネントの実装を確認
   - ブラウザのキャッシュをクリア
