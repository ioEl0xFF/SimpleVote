# ホームページテスト

このディレクトリには、SimpleVote アプリケーションのホームページ（`/`）に関する包括的な E2E テストが含まれています。

## 📁 ファイル構成

```
tests/e2e/homepage/
├── README.md                           # このファイル
├── homepage.spec.ts                    # 基本機能テスト
├── homepage-loading.spec.ts            # ローディング状態テスト
├── homepage-error.spec.ts              # エラー状態テスト
└── homepage-accessibility.spec.ts      # アクセシビリティテスト
```

## 🚀 テスト実行方法

### 全テストの実行

```bash
# ホームページの全テストを実行
npm run test:e2e:homepage:all

# または
npx playwright test tests/e2e/homepage/
```

### 個別テストの実行

```bash
# 基本機能テストのみ
npm run test:e2e:homepage:basic

# ローディング状態テストのみ
npm run test:e2e:homepage:loading

# エラー状態テストのみ
npm run test:e2e:homepage:error

# アクセシビリティテストのみ
npm run test:e2e:homepage:a11y
```

### デバッグモードでの実行

```bash
# ヘッドレスモードで実行（ブラウザが表示される）
npx playwright test tests/e2e/homepage/ --headed

# UIモードで実行（Playwright Test UIが起動）
npx playwright test tests/e2e/homepage/ --ui

# デバッグモードで実行（ステップ実行可能）
npx playwright test tests/e2e/homepage/ --debug
```

### 特定のテストのみ実行

```bash
# 特定のテストケースのみ実行
npx playwright test tests/e2e/homepage/ --grep "ページが正常に読み込まれる"

# 特定のテストファイルの特定のテストケースのみ実行
npx playwright test tests/e2e/homepage/homepage.spec.ts --grep "投票一覧"
```

## 📋 テスト実行前の準備

### 1. 開発サーバーの起動

```bash
# 開発サーバーを起動
npm run dev
```

### 2. 環境変数の確認

必要な環境変数が設定されていることを確認してください：

```bash
# .env.local ファイルに以下が設定されていることを確認
NEXT_PUBLIC_POLL_REGISTRY_ADDRESS=0x...
NEXT_PUBLIC_CHAIN_ID=31337
```

### 3. 依存関係のインストール

```bash
# Playwrightの依存関係をインストール
npx playwright install
```

## 🐛 トラブルシューティング

### よくある問題と解決方法

1. **テストがタイムアウトする**

    - 開発サーバーが起動していることを確認
    - ネットワーク接続を確認
    - タイムアウト値を調整

2. **モックが正しく動作しない**

    - モック設定を確認
    - ページのリロードが必要な場合がある

3. **要素が見つからない**

    - セレクタが正しいことを確認
    - ページの読み込み完了を待機

4. **ウォレット接続が失敗する**
    - モック設定を確認
    - ブラウザの設定を確認
